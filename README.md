# PNR – AI Telegram Bot

ربات هوش مصنوعی تلگرام.

## وضعیت فعلی

این ریپازیتوری در حال حاضر فقط شامل یک فایل آرشیو (`pnr-ai-main.rar`) است.

برای حرفه‌ای شدن پروژه پیشنهاد می‌شود:

1. فایل‌های سورس را از آرشیو خارج کنید و در ریشه ریپو قرار دهید.
2. یک `requirements.txt` یا `package.json` مناسب اضافه کنید.
3. README را با دستورالعمل اجرای واقعی به‌روزرسانی کنید.

## پیشنهاد بعدی

- استخراج کد از فایل rar
- اضافه کردن `.gitignore`
- استفاده از متغیر محیطی برای توکن ربات
- اضافه کردن لایسنس MIT
